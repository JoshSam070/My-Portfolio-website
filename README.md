# Personal Portfolio Website

## About the Project

This project is a personal portfolio website designed to showcase my professional background, career journey, skills, and contact information. It provides a simple and professional online presence where recruiters, potential employers, and professional connections can learn more about me.

The website consists of two pages:

- **Home Page:** Introduces me, highlights my professional profile, and presents relevant career information.
- **Contact Page:** Provides contact information and a convenient way for visitors to connect with me regarding professional opportunities.

## Features

- Clean and professional user interface
- Dedicated home and contact pages
- Career-focused personal branding
- Simple and user-friendly navigation
- Easy access to contact information

## Purpose

The primary goal of this project is to establish an online professional presence, showcase my portfolio, and make it easier for recruiters and potential employers to connect with me.
